Packs now install without a clone (linked PR, 0.3.23): a pack entry can use `git = "<url>"` (plus an optional `ref`) instead of `path`. `apply` fetches it once into `~/.config/ai-config/packs/<name>`, and the new `aicfg update` refetches at the pinned ref. Private repos work through your own git credentials. Checked with the uv-installed aicfg fetching a pack from a bare repo and updating it from v1 to v2. With this, core and packs both install without a clone; Cursor and the OpenCode guard plugin remain.
