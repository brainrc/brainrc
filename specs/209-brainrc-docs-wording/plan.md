## Approach
A new test, `tests/test_old_names.py`, lists files with `git ls-files --cached --others --exclude-standard`. That covers hidden files such as `.github/` and `.pre-commit-config.yaml` and skips `.git/`. It drops `CHANGELOG.md`, `changelog.d/` and `specs/`. `ALLOW` is one table of `(path glob, regex, reason)` rows. For each line, the test deletes every match of the rows whose glob fits the path, then fails if `(?i)aicfg|ai-config` is still in what is left. This way a line with one allowed name and one leftover still fails. Any row that matches no line also fails (AC2). Rows follow categories A-F:
- A and F: whole-file `.*` rows.
- B, C and D: exact tokens, e.g. `AICFG_HOME`, `"ai-config"` in `config.py`, `OWNED_HOOK`, `bak-(?:brainrc|aicfg)`, `ai-config@ai-config`, `plugins/local/ai-config`, `BLOCK_START`/`BLOCK_END`, `FETCHED`, `ai-config-guard\.js`, `deprecated_entry`/`warn_deprecated("aicfg")`.
- E: exact old tokens, plus `aicfg|ai-config` only on lines that also contain `old|former|deprecated|legacy`.

Test files that exist to exercise old names get whole-file rows. These are `test_cli_entry_points`, `test_settings_home`, `test_migrate`, `test_doctor_home`, `test_doctor_plugin`, `test_rename_converge`, `test_ownership`, `test_backups`, `test_plugin_docs` and `test_active_run`. `test_brainrc.py`, `test_hooks.py` and `test_mcp.py` get exact legacy-token rows.

Wording tasks then fix the hits group by group, without touching code paths in C. The test module rename drops the alias: `import brainrc` replaces `import brainrc as aicfg`, and `self.settings_home` replaces `self.aicfg_home` in `TempRepoCase`. Its importers (`test_mcp`, `test_rename_converge`, `test_hooks`) follow. Identifier renames reuse `config.home_origin()` and `config.aicfg_home()` (renamed in place). The CLI keeps its `config.command()` helper for printed commands. Living-spec wording (AC8) is done at the document stage, not by a task.
