Rename the plugin and marketplace to brainrc

## Why
Plugin users install `ai-config@ai-config` today, and skills show as `ai-config:<name>`. With the tool
renamed to `brainrc`, the plugin and marketplace follow. Existing plugin users have to reinstall, so
the docs say how and `doctor` reminds them. 5 of 6 in epic #199 (rename to brainrc), after #233.

## What changed
- **[pack contract]** The plugin and marketplace are named `brainrc` in the Claude Code, Codex,
  Cursor and Antigravity manifests, regenerated by `scripts/brainrc.py plugin`. In Claude Code,
  skills show as `brainrc:<name>` (`/brainrc:work`).
- `brainrc doctor` warns when the old plugin is still installed:
  - Claude Code: the exact key `ai-config@ai-config` in `~/.claude/plugins/installed_plugins.json`.
  - Cursor: `~/.cursor/plugins/local/ai-config`.
  Each warning comes with the uninstall steps. Doctor only reads these files, and a missing, huge,
  malformed, deeply nested or unreadable file gives no finding and no error.
- Install docs and the README use `brainrc@brainrc`. A new "Moving from ai-config" section covers
  the uninstall, and troubleshooting points at the doctor warning.
- spec-agent looks up roles as `brainrc:<role>`, then `ai-config:<role>` for an old install.
