- npx (#278): `npx github:brainrc/brainrc status` runs brainrc from Node through `uvx`, pinned to the repo's `VERSION`, so it needs uv but no Python; without uv the shim says how to get it and exits 127. A root `package.json` (generated by `brainrc plugin` with the other manifests, `private`, no dependencies or scripts) points `bin` at `bin/brainrc.js`; the release commits it with the new version, and `validate` fails when it is stale or the shim is missing. The docs warn that `npx brainrc` without `github:` would run an unrelated npm package. Nothing is published to npm, and the route works once the repo is public. CI packs the repo and runs the shim against a wheel of the checkout.
